# Assets Folder

This folder is for storing:
- Product images
- Logo files
- Icon files
- Other media files

## Usage

Place your bakery images here and reference them in the code like:
```html
<img src="assets/product-name.jpg" alt="Product Name">
```

## Recommended Image Sizes

- **Product Images**: 300x300px (square)
- **Hero Banner**: 1920x400px
- **Logo**: 200x100px
- **Thumbnail**: 100x100px
